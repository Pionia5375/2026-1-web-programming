### [0:00] 인사

안녕하세요.
컴퓨터공학부 202100580 이정입니다.
이번 학기 기말 프로젝트, **PlanIt** 을 발표하겠습니다.

### [0:15] 왜 만들었는가

대학생이 매일 다루는 일정은 두 가지입니다.
강의·시험처럼 **시각이 정해진 일정**,
그리고 과제·보고서처럼 **마감일이 있는 작업** 입니다.

시중 도구는 캘린더 앱과 투두 앱이 분리되어 있어 두 앱을 오가야 합니다.
PlanIt 은 둘을 **하나의 모델로 묶어 한 화면에 모은 서비스** 입니다.

### [0:45] 핵심 기능

핵심 기능은 여섯 가지입니다.
JWT 기반 인증,
우선순위 있는 할 일,
시간과 장소가 있는 일정,
한국어 통합 캘린더,
오늘 마감 + 오늘 일정을 보여 주는 대시보드,
다크 모드와 마감 1시간 전 브라우저 알림입니다.

### [1:10] 전체 아키텍처

구조를 짚어 보겠습니다.
브라우저는 **Vercel** 에서 React 정적 자원을 받고,
`/api` 요청만 **Render 위의 Docker 컨테이너** 로 갑니다.
Express + Prisma 가 처리하고, 데이터는 **Neon Postgres** 에 영속됩니다.
응답은 **IndexedDB** 에 캐시되어 네트워크 장애에도 마지막 데이터를 보여 줍니다.

### [1:45] 기술 스택

스택은 수업에서 다룬 요소 그대로입니다.
프런트엔드는 React · Vite · Tailwind,
백엔드는 Express · Prisma · JWT · zod,
운영은 PostgreSQL · Docker · Nginx · GitHub Actions 입니다.

### [2:05] 조건 ① — DBMS 활용

이제 제출 조건 세 가지를 차례로 보여 드리겠습니다.

첫 번째, **DBMS** 입니다.
사용자와 할 일, 사용자와 일정은 모두 **1대 다 관계** 라 관계형 모델이 자연스러웠습니다.
스키마는 **Prisma** 로 정의하고 마이그레이션 파일은 그대로 운영에 적용됩니다.
사용자와 마감 시각에 **복합 인덱스** 를 걸어 캘린더 쿼리를 가속했고,
운영 DB 는 **Neon 서버리스 Postgres** 를 SSL 강제로 연결했습니다.

### [2:40] 조건 ② — Web Storage 활용

두 번째, **Web Storage** 입니다.
저장소를 단순히 같이 쓰는 게 아니라 **수명과 범위에 따라 네 계층** 으로 나눴습니다.

영속 데이터 본체는 PostgreSQL,
토큰과 테마는 **localStorage**,
검색어와 마지막 본 월은 **sessionStorage**,
오프라인 폴백 캐시는 **IndexedDB** 입니다.

이렇게 각 데이터의 수명이 분명하도록 분담했습니다.

### [3:15] 조건 ③ — Docker

세 번째 조건, **Docker** 입니다.
`docker compose up` 한 번으로 **web · api · db 세 컨테이너** 가 동시에 뜹니다.
`pg_isready` 헬스체크 통과 후 api 가 부팅됩니다.
이미지는 **multi-stage build** 로 슬림하게 줄였고,
베이스를 **node:20-slim** 으로 잡은 것은 Prisma 의 Alpine OpenSSL 이슈를 피하기 위함입니다.

### [3:45] 조건 ③ — Nginx 리버스 프록시

같은 조건의 **Nginx** 입니다.
웹 컨테이너의 Nginx 가 `/api` 는 백엔드로 리버스 프록시,
나머지는 React 빌드를 직접 응답합니다.

이 한 가지로 **CORS 가 불필요** 해지고,
gzip 으로 JS 가 138 KB 까지 줄고,
정적 자산 1년 immutable 캐시로 재방문 다운로드가 0 바이트가 됩니다.
SPA 새로고침 200 응답도 보장됩니다.

### [4:15] 조건 ④ — CI/CD 자동 배포

마지막 조건, **CI/CD** 입니다.
main 으로 push 가 들어오면 세 가지가 동시에 일어납니다.

**GitHub Actions** 의 `ci.yml` 이 server·client·docker compose 빌드를 검증하고,
**Vercel** 의 GitHub 연동이 프런트엔드를 자동 배포하고,
**Render** 의 autoDeploy 가 백엔드 Docker 이미지를 빌드 + 마이그레이션까지 적용합니다.

실제로 이 프로젝트는 여러 PR 을 머지하며 **무중단** 으로 반영되었습니다.

### [4:55] 보안 · UX

기술 마무리로,
bcrypt · JWT · zod 로 인증과 입력을 보호하고,
axios 인터셉터가 401 응답에서 자동 로그아웃을 처리합니다.
CORS 화이트리스트, 오프라인 캐시, OS 다크 모드 감지로 사용자 경험을 다듬었습니다.

### [5:15] 라이브 시연  ((브라우저 전환))

이제 실제 사이트에서 한 사이클 보여 드리겠습니다.

로그인합니다.
대시보드는 오늘 마감과 오늘 일정을 자동으로 표시합니다.

할 일을 추가합니다 — 제목 "보고서 작성", 우선순위 상.
검색창에 단어를 넣으면 즉시 필터되고, 검색어는 **sessionStorage** 에 유지됩니다.

일정을 추가합니다 — 제목 "수업", 장소 "공학관", 10시부터 11시 30분.
시간이 잘못되면 서버 **zod** 가 막아 줍니다.

캘린더로 이동합니다.
한 화면에 일정은 파란색, 할 일은 노란색으로 표시되고,
월·주·일·아젠다 네 뷰가 한국어로 동작합니다.

다크 모드를 켭니다.
새로고침해도 유지되는데, **localStorage** 에 저장되기 때문입니다.

미리 등록한 마감 한 시간 이내 할 일에 대해 **브라우저 알림** 이 뜹니다.

마지막으로 개발자 도구에서 **IndexedDB** 의 `planit-cache` 를 열어 보면,
할 일과 일정이 캐시되어 오프라인 폴백에 쓰입니다.

### [6:45] 마무리  ((마무리 슬라이드 복귀))

정리하면, PlanIt 은 14주차 설계서를 그대로 구현해
**CI/CD · Docker · Nginx · Web Storage · DBMS** 다섯 조건을 모두 적용한 풀스택 프로젝트입니다.

서비스 URL 과 GitHub 저장소는 슬라이드에 표시되어 있습니다.
한 학기 동안 좋은 강의 감사드립니다.

**감사합니다.**
